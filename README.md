# 🎹 Instrument Trainer - 键盘手与编曲者的专属练习器

一个专为** MIDI 键盘手**与**编曲人**打造的 Web 端练习工具。不做古典演奏家，只专注于一件事：**把脑子里想到的声音，准确、顺畅地落到键盘上。**

✨ **纯原生前端实现** | 🎨 **粉色毛玻璃 UI** | 🎼 **智能五线谱实时渲染**

---

## 🌟 核心特性

本项目不追求“手速”、“力度”与“古典表现力”，而是针对编曲时“按和弦、找灵感、扒带”的真实场景设计了三大模块：

### 1. 和弦练习 (Chords)
- **和弦构造**：系统随机出题（如 `Cmaj7`），你需要在键盘上按出对应音。支持**宽松/严格**（缺五音算不算对？）和**多按音宽容/严格**独立配置。
- **和弦转位**：指定转位（如 `C/E`），系统不仅判定音高，还专门判定**最低音**是否正确。
- **和弦识别**：你随便按，系统实时告诉你这是什么和弦（支持转位识别，如 `C/E`）。
- **和弦进行**：内置流行/爵士经典进行（如 `ii-V-I`），跟随五线谱与和弦卡片弹奏。基于 JSON 动态渲染小节线。

### 2. 音阶练习 (Scales)
- **顺序跟弹**：手把手带你跑上下行，弹对一个亮一个。内藏**循环移调**开关，弹完 C 调自动升半音练 Db 调。
- **调式回忆（独有玩法）**：只给你一个名字（如 `D Dorian`），不给任何提示。你凭记忆弹，弹对一个五线谱上就“长”出一个音，错音标红。
- **随机抽音**：从当前调式中随机报一个音，考验你对键位的条件反射。
- **补缺音**：五线谱上挖空一个音，你需要顺着弹，遇到挖空处（显示为 `?`）时凭记忆补全。
- **盲弹定位**：隐藏虚拟键盘，系统报音名或音程（如“纯四度”），你用实体键盘盲摸。

### 3. 听辨复现 (Ear Training)
- 分为 **单音、音程、和弦、音阶** 四个独立模式。
- 系统播放声音，完全不给视觉提示，你需要靠耳朵听出音高并在键盘上复现。

## 🛠️ 硬核技术亮点

1. **变态级的五线谱渲染引擎**：
   - 内置了**“智能加线寻找算法”**：遇到大跨度和弦时，自动计算“上移”还是“下移”产生的加线最少，保证谱面始终优雅。
   - **调号与临时升降号完美处理**：自动根据同主音大调生成调号。比如自然小调里遇到降 3 级，会精准打上降号（♭）；遇到旋律小调下行，会自动打上还原号（♮）。
   - 支持**横向等宽瀑布流**排列音阶，以及**和弦垂直叠置**的混合排版。
2. **零卡顿的 MIDI 接入**：采用全局 `midiManager` 统一接管硬件事件，避免了多个练习模式反复连接导致底层端口死锁的 Chromium 历史遗留 Bug。
3. **极简现代 UI**：纯 CSS 实现的 Glassmorphism（毛玻璃）+ 粉色渐变视觉系统。

## 🚀 快速开始

本项目采用 **纯原生 HTML + CSS + JavaScript (ES Modules)** 编写，**无需任何构建工具（No Node.js, No Vite, No Webpack）**。

### 运行步骤：
1. Clone 或下载本仓库到本地。
2. 使用任意静态服务器打开项目根目录（例如 VS Code 的 `Live Server` 插件，或 Python 的 `python -m http.server`）。
3. **推荐使用 Chrome 或 Edge 浏览器** 访问 `localhost` 地址。
   > *注：Web MIDI API 强制要求 HTTPS 或 localhost 环境。Safari 浏览器目前不支持 Web MIDI。*
4. 点击页面上的“连接 MIDI 设备”，允许浏览器权限，即可开始练习。
